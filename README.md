# Appareo

This repository contains firmware for an STM32 microcontroller demo using the HTS1510 pressure and temperature sensor. Two PWM outputs drive 4-20 mA loops for pressure (0–175 psia) and temperature (-60 °C to 50 °C).

## nh3 Program

`nh3.c` implements the demonstration firmware. Key features:

- Two 10 kHz PWM outputs driving 4–20 mA loops.
- HTS1510 sensor polling every 100 ms.
- Optional UART1 logging of readings.
- Continuous watchdog refresh.

Open the project in STM32CubeIDE or build `nh3.c` with `arm-none-eabi-gcc`/`make`.

When logging is enabled the UART prints lines such as:

```
P= 25.05 psia (raw=7031) | T=+75.2 F (raw=10900)
```

Set `ENABLE_LOGGING` to `0` near the top of the file to disable these messages.

API documentation generated by Doxygen is stored in [nh3_doxygen.txt](nh3_doxygen.txt). Run `doxygen` to regenerate it.

## Building

Open the project in STM32CubeIDE or compile `nh3.c` with `arm-none-eabi-gcc`/`make`. The firmware depends on the STM32 HAL libraries.

## Hardware

- HTS1510 sensor on I2C1 (PB6/PB7)
- PWM output TIM1_CH1 on PA5 for temperature
- PWM output TIM3_CH1 on PA6 for pressure
- UART1 at 115200 baud for optional logging
- Independent watchdog with ~4 s timeout

## Logging

Define `ENABLE_LOGGING=1` at compile time to emit diagnostic UART messages. Undefine it for production builds to save bandwidth.
